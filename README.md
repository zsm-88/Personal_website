

# 个人网站

一个展示个人作品、项目和技术文章的平台，致力于分享编程经验与技术知识，助力开发者成长。

## 网站结构

本项目是一个静态个人网站，包含以下主要页面：

- **首页 (index.html)** - 展示个人简介、技能、项目作品和联系方式
- **简历页 (resume.html)** - 在线简历，展示工作经验和技能

## 技术栈

- **HTML5** - 语义化标记
- **Tailwind CSS** - 响应式样式设计，支持深色模式

## 主要功能

### 首页功能
- **导航栏** - 响应式设计，支持移动端菜单折叠
- **个人简介** - 展示个人背景和核心技能
- **技能展示** - 三张卡片展示不同领域的专业能力
- **项目作品** - 展示个人项目作品集
- **联系方式** - 社交链接和联系方式模态框

### 简历页功能
- **在线简历** - 可打印的简历格式
- **工作经验** - 详细的工作经历列表
- **技能列表** - 专业技能展示
- **教育背景** - 教育经历信息

## 快速开始

1. 克隆本仓库：
   ```bash
   git clone https://gitee.com/zsm_888888/personal-website.git
   ```

2. 直接在浏览器中打开 `index.html` 即可预览网站

## 自定义修改

### 修改个人信息
编辑 `index.html` 中的以下内容：
- 导航栏中的姓名和链接
- 关于我 section 中的个人简介
- 技能卡片中的内容
- 项目展示中的作品信息

### 修改联系方式
在 `index.html` 的联系 section 中修改：
- 社交媒体链接
- 联系邮箱

### 修改简历内容
编辑 `resume.html` 中的：
- 个人基本信息
- 工作经历
- 技能列表
- 教育背景

## 页面预览

- **首页**：展示个人品牌、作品集和联系方式
- **简历页**：专业的在线简历，支持打印输出
